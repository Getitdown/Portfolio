Online Garden Store

This project is a web application for an online store specializing in home and garden products. The site provides users with a convenient interface for browsing products, categorizing them, adding items to a cart, and placing orders.

Hangman Game

The Hangman game is a classic word-guessing challenge. Players try to guess a hidden word by selecting letters, with each incorrect guess bringing them closer to the "hangman". The game features a clean and responsive interface, making it enjoyable to play on both desktop and mobile devices. It's a fun and educational way to test your vocabulary and logical thinking!
